OPERATING PRINCIPLES

Security rules we expect every project to follow

Never share seed phrases

Seed phrases and private keys should remain with the wallet owner.

Separate project wallets

Use clearly defined founder, treasury, liquidity and community wallets where appropriate.

Verify before signing

Review transaction destination, amounts and instructions before approving a wallet signature.

Publish key references

Official mint, pool, lock and vesting links should be made easy for the community to verify.
